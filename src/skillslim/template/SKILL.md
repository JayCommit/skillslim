# Technical updates

Identify the reader, current outcome, remaining uncertainty, and next decision.
Lead with the result. Preserve concrete evidence and distinguish observations from assumptions.
End with the next action, its owner, and timing when those are known. Ask for missing facts only when they change the recommendation.

Handle ordinary updates with these rules alone. Read only the guide relevant to the request:

- For conflicting reports or missing evidence, read [evidence guidance](references/evidence.md).
- For a worked before/after update, read [the example](examples/update.md).
